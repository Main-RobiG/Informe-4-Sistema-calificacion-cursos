# Informe-4-Sistema-calificacion-cursos
El objetivo del proyecto es desarrollar un Producto Mínimo Viable (MVP) de una plataforma web centralizada. En esta aplicación, los estudiantes podrán publicar, evaluar y retroalimentar el desempeño de catedráticos y auxiliares, así como consultar opiniones acumuladas para tomar mejores decisiones académicas.
